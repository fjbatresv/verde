`init.sh` copia estas dos plantillas a tu proyecto. Los archivos viven en
[`templates/`](https://github.com/fjbatresv/verde/tree/main/templates) del repo.

## Vault

El vault es la memoria del proyecto: un repo privado de notas en Markdown,
pensado para Obsidian.

<FileTree>
- tu-proyecto-vault/

  - 02-Backlog/
    - Backlog.md épicas, issues y criterios
  - 03-Encargos/ un encargo por trabajo asignado
  - 04-Decisiones/

## La puerta

`gate.steps` declara los pasos; `local-gate.sh` los corre y responde verde o
rojo. La plantilla trae ejemplos para Node, Python, Go, Java, .NET y monorepos.

```text
# <kind> <name>: <command>
step format: npx prettier --check .
step lint: npm run lint
step test: npm test
setup ports-free: for p in 3000 5432; do (exec 3<>/dev/tcp/127.0.0.1/$p) 2>/dev/null && exit 1; done; exit 0
setup infra: docker compose up -d --wait
step e2e: npx playwright test
teardown infra-down: docker compose down
step ?snyk: snyk test --severity-threshold=high
```

Las reglas completas están en [el estándar, sección 8](/estandar/#8-la-puerta).
