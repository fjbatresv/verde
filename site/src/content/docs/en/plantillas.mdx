`init.sh` copies these two templates into your project. The files live in
[`templates/`](https://github.com/fjbatresv/verde/tree/main/templates) in the
repo. Folder and file names are in Spanish, as they ship.

## Vault

The vault is the project's memory: a private repo of Markdown notes, designed
for Obsidian.

<FileTree>
- your-project-vault/
  - 00-Inicio.md status, team and map of the vault
  - 01-Producto/ vision, scope and roadmap
  - 02-Backlog/
    - Backlog.md epics, issues and criteria
  - 03-Encargos/ one brief per assigned piece of work
  - 04-Decisiones/
    - Registro-de-decisiones.md `D-xxx` with date, origin and status
  - 05-Reuniones/ meetings
  - 06-Revisiones/ one note per PR, with its rounds
  - 07-Plantillas/ note templates
    - Plantilla-Encargo.md brief
    - Plantilla-Revision.md review
    - Plantilla-Decision.md decision
    - Plantilla-Reunion.md meeting
    - Plantilla-Status.md status
  - 08-Status/ day status
  - 99-Adjuntos/ screenshots and diagrams
</FileTree>

## The gate

`gate.steps` declares the steps; `local-gate.sh` runs them and answers green or
red. The template ships examples for Node, Python, Go, Java, .NET and
monorepos.

```text
# <kind> <name>: <command>
step format: npx prettier --check .
step lint: npm run lint
step test: npm test
setup ports-free: for p in 3000 5432; do (exec 3<>/dev/tcp/127.0.0.1/$p) 2>/dev/null && exit 1; done; exit 0
setup infra: docker compose up -d --wait
step e2e: npx playwright test
teardown infra-down: docker compose down
step ?snyk: snyk test --severity-threshold=high
```

The full rules are in [the standard, section 8](/en/estandar/#8-the-gate).
